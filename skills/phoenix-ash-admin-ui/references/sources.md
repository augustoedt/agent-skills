## Como usar as referências

Use como referência de:

- composição;
- hierarquia;
- tokens;
- responsividade;
- acessibilidade;
- estados de componentes.

Não rode `bun x shadcn-svelte ...` dentro de projeto Phoenix. Não adicione Svelte ao runtime. Os assets da skill são implementações Phoenix/HEEx genéricas e pertencem ao projeto que os recebe.

## Licença

O shadcn-svelte é MIT. Uma cópia da licença analisada está em:

```text
assets/LICENSE-shadcn-svelte-MIT.txt
```

Ao copiar ou adaptar porções substanciais diretamente do upstream para um projeto, preserve a licença e atribuição nesse projeto. Inspiração visual e reimplementação original não devem ser representadas como componentes oficiais do shadcn-svelte.

## PhiaUI

PhiaUI não é fonte nem dependência desta skill. Projetos antigos podem ter componentes adaptados sob MIT; preserve a atribuição específica deles durante migração até que sejam reescritos ou removidos.
